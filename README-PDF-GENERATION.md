# PDF Generation with Firebase Cloud Functions

This project uses Firebase Cloud Functions to generate PDFs because Vercel's hobby plan doesn't support server-side Puppeteer execution.

## Setup Instructions

### 1. Firebase Project Setup

1. Create a Firebase project at [Firebase Console](https://console.firebase.google.com/)
2. Enable the Cloud Functions feature (you may need to upgrade to the Blaze plan, which is pay-as-you-go)
3. Install Firebase CLI globally: `npm install -g firebase-tools` or `yarn global add firebase-tools`
4. Login to Firebase: `firebase login`
5. Initialize your project with Firebase: `firebase use --add` and select your project

### 2. Create Service Account

1. Go to Firebase Console > Project Settings > Service Accounts
2. Click "Generate new private key"
3. Save the JSON file securely (don't commit it to version control)

### 3. Environment Variables Configuration

Create a `.env.local` file at the root of your project with the following content:

```
# Firebase Configuration (Client)
NEXT_PUBLIC_FIREBASE_API_KEY=your-api-key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your-project-id.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your-project-id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your-project-id.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your-messaging-sender-id
NEXT_PUBLIC_FIREBASE_APP_ID=your-app-id

# Firebase Admin Configuration (Server)
FIREBASE_PROJECT_ID=your-project-id
FIREBASE_CLIENT_EMAIL=your-service-account-email@your-project-id.iam.gserviceaccount.com
FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nYour Private Key Here\n-----END PRIVATE KEY-----\n"
```

You can find these values:

- Client values: Firebase Console > Project Settings > General tab
- Admin values: In the service account JSON file you downloaded

### 4. Deploy Firebase Function

1. Install dependencies: `cd functions && npm install`
2. Build the function: `npm run build`
3. Deploy the function: `firebase deploy --only functions`

### 5. Vercel Environment Variables

If deploying to Vercel, add all the environment variables from `.env.local` to your Vercel project:

1. Go to Vercel Dashboard > Your Project > Settings > Environment Variables
2. Add each variable from your `.env.local` file
3. Remember to properly format the `FIREBASE_PRIVATE_KEY` with newline characters (\n)

## How It Works

1. The application first tries to generate PDFs directly through the API route
2. If the API route fails (which will happen on Vercel's hobby plan), it falls back to the Firebase Cloud Function
3. The Firebase function uses Puppeteer to generate the PDF and returns it as a base64-encoded string
4. The client converts the base64 string back to a PDF and displays it

## Costs

Firebase Cloud Functions are part of the Blaze (pay-as-you-go) plan:

- First 2 million invocations per month are free
- $0.40 per million invocations thereafter
- You also pay for compute time and outbound data
- For PDF generation, with higher memory requirements, it may cost a few cents per thousand PDFs

See [Firebase Pricing](https://firebase.google.com/pricing) for details.

## Development vs Production

- In development (local), PDFs will be generated directly by the API route using local Puppeteer
- In production (Vercel), PDFs will be generated by the Firebase Cloud Function

## Troubleshooting

If PDF generation fails:

1. Check Firebase Cloud Function logs in the Firebase Console
2. Verify that all environment variables are correctly set
3. Ensure the Firebase function is properly deployed
4. Check if the Blaze plan is active (required for Cloud Functions)
5. Verify that your service account has the necessary permissions
